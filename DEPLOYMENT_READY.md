## 🚀 Deployment Steps

### Phase 1: Backend Deployment (5 minutes)

#### Step 1: Create Render Service
1. Go to https://render.com
2. Sign in with GitHub account
3. Click **"New Web Service"**
4. Connect **vishal-timbadiya/EcomZone** repository
5. Select **Master** branch

#### Step 2: Configure Service
- **Service Name:** `ecomzone-backend`
- **Environment:** Node
- **Region:** Oregon (or your preferred region)
- **Branch:** master
- **Build Command:** `npm run build`
- **Start Command:** `node dist/server.js`
- **Instance Type:** Starter (minimum)
- **Root Directory:** `./backend`

### Phase 2: Frontend Deployment (5 minutes)

#### Step 1: Create Vercel Project
1. Go to https://vercel.com
2. Sign in with GitHub account
3. Click **"New Project"**
4. Import **vishal-timbadiya/EcomZone** repository
5. Select **Master** branch

#### Step 2: Configure Project
- **Framework:** Next.js (auto-detected)
- **Root Directory:** `./frontend`
- **Build Command:** `npm run build`
- **Output Directory:** `.next`
- **Install Command:** `npm install`

#### Step 3: Set Environment Variables
Add this in Vercel project settings:

```
NEXT_PUBLIC_API_URL = https://ecomzone-backend-xxxxx.onrender.com
```

*(Replace with your actual Render backend URL from Phase 1)*

#### Step 4: Deploy
- Click **"Deploy"**
- Wait for build and deployment (2-3 minutes)
- Note the deployment URL: `https://your-domain.vercel.app`

---

### Phase 3: Update Backend (2 minutes)

#### Update Frontend URL
1. Go to Render dashboard
2. Select **ecomzone-backend** service
3. Go to **Environment**
4. Update `FRONTEND_URL`:
   ```
   FRONTEND_URL = https://your-vercel-domain.vercel.app
   ```
5. Service will auto-redeploy

## 🆘 Troubleshooting

### Frontend Build Fails
- Check `frontend/package.json` exists
- Verify `frontend/app/` directory exists
- Check `NEXT_PUBLIC_API_URL` is set in Vercel

### Backend Build Fails
- Check `backend/package.json` exists
- Verify `backend/src/` directory exists
- Ensure TypeScript compilation works: `npm run build`

### API Connection Error
- Verify backend URL is correct in `NEXT_PUBLIC_API_URL`
- Check backend is running: curl `https://your-backend/health`
- Check CORS configuration in backend

### Database Connection Error
- Verify `DATABASE_URL` in Render environment variables
- Test connection string locally: `psql <connection_string>`
- Check PostgreSQL user permissions

### Image Upload Not Working
- Verify image upload directory is writable
- Check file size limits in backend config
- Verify multer configuration
